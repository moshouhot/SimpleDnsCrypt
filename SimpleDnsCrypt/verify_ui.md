# SimpleDnsCrypt UI 验证指南

## 1. 托盘菜单验证

### 修改前的问题
- 托盘右键菜单左侧有多余空间
- 菜单项显示为 "√ 开机自启" 或 "× 开机自启"
- 界面不够紧凑

### 修改后的改进
- 使用WPF原生的 `IsChecked` 属性
- 菜单项显示为 "开机自启"，前面有标准的勾选框
- 界面更加紧凑和美观

### 验证步骤
1. **启动程序**: 运行 SimpleDnsCrypt.exe
2. **查看托盘**: 在系统托盘中找到 SimpleDnsCrypt 图标
3. **右键菜单**: 右键点击托盘图标
4. **检查菜单**: 观察菜单项的显示效果
   - 应该看到 "开机自启" 菜单项
   - 如果开机自启已启用，菜单项前应该有勾选标记 ✓
   - 如果开机自启未启用，菜单项前应该没有勾选标记
   - 菜单项之间应该有分隔线
   - 左侧不应该有多余的空间

## 2. 设置窗口验证

### 验证步骤
1. **打开设置**: 在主界面点击 "设置" 按钮
2. **查看选项**: 找到原来的 "静默安装新版本" 位置
3. **检查标签**: 现在应该显示为 "开机自启"
4. **测试功能**: 
   - 勾选该选项，检查注册表是否添加启动项
   - 取消勾选，检查注册表是否删除启动项

## 3. 状态同步验证

### 验证步骤
1. **通过设置窗口修改**: 在设置中勾选/取消勾选开机自启
2. **检查托盘菜单**: 右键托盘图标，查看菜单项状态是否同步
3. **通过托盘菜单修改**: 点击托盘菜单中的开机自启项
4. **检查设置窗口**: 打开设置窗口，查看选项状态是否同步

## 4. 默认开机自启验证

### 当前配置
```xml
<Setting Name="AutoStart" Type="System.Boolean" Scope="User">
  <Value Profile="(Default)">True</Value>
</Setting>
```

### 验证步骤
1. **删除配置**: 删除用户配置文件（让程序使用默认值）
2. **重新启动程序**: 启动 SimpleDnsCrypt
3. **检查状态**: 
   - 设置窗口中的开机自启应该是勾选状态
   - 托盘菜单中的开机自启应该有勾选标记
   - 注册表中应该有 SimpleDnsCrypt 启动项

## 5. 注册表验证命令

```cmd
# 查看开机自启动项
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SimpleDnsCrypt

# 手动添加开机自启动项（测试用）
reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SimpleDnsCrypt /t REG_SZ /d "\"C:\Path\To\SimpleDnsCrypt.exe\""

# 手动删除开机自启动项（测试用）
reg delete "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SimpleDnsCrypt /f
```
